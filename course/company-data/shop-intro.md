# 里歐烘焙坊（虛構的店，課程用）

## 這家店是什麼

- 一間**中央廚房**＋兩家**門市**（中山店、大安店），每天 08:00–20:00 營業。
- 廚房就是工廠：每天出爐的門市麵包有固定的品項、價格、產量；另外接**客製蛋糕**和**喜餅、彌月禮盒團訂**，這些是定做的——尺寸、口味、造型、字樣、交期都要談，收訂金，造型太難要師傅確認，加急要店長核准。
- 門市就是服務業：客人問品項、問過敏原、下訂、改單、退訂。

## 兩種產出

| | 固定產出 | 定做 |
|---|---|---|
| 是什麼 | 門市每天出爐的麵包、切片蛋糕 | 客製蛋糕、彌月禮盒、喜餅禮盒 |
| 品項與價格 | 固定（見〈門市品項〉） | 依選項計算（見〈客製蛋糕選項表〉） |
| 流程 | 當天做當天賣 | 規格確認 → 報價 → 訂金 → 排產 → 交期 |
| 誰決定 | 照每日產量做 | 產能、前置天數是程式算；加急、取消、超額折扣、請假由店長核准 |

## 店的處境（為什麼要請 AI）

- 阿珠姨快退休，知識只在她腦裡。
- 訂單寫在舊的訂單系統裡，只有店長查得到；旺季電話一多就漏接、交期就撞。
- 老闆想用 AI 接單、回客人，但**不想每個店員都買 Claude**。
