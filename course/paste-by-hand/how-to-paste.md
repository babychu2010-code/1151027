# 手工貼一個 Worker 到 Cloudflare（約 10 分鐘，不經過 Claude）

目的：**親手**把一段程式放上 Cloudflare、打開網址看到它跑。做得到，就證明你的帳號和瀏覽器環境是通的；之後 Claude 替你做的，就是同一件事。

| 步驟 | 你做什麼 | 做完你應該看到 |
|---|---|---|
| 1 | 打開本資料夾的 `paste-and-run.js`，按 GitHub 檔案右上角的「Copy raw file」（或全選複製） | 剪貼簿裡有一整段程式 |
| 2 | 打開 **Cloudflare**——就是剛剛裝 Arcrun RAG 時登入的那個帳號，瀏覽器已經登入了（關掉了就到 dash.cloudflare.com 用同一個帳號登入）→ 左邊選單 **Workers & Pages** → **Create** → 選 **Worker**，從「Hello World」範本開始，名字取 `my-first-worker`（小寫英文、數字、減號），按 **Deploy** | 畫面說部署成功，給你一個 `https://my-first-worker.<你的名字>.workers.dev` 網址 |
| 3 | 按 **Edit code**。在程式編輯器裡 **全選、刪掉、貼上** 剛才複製的那一整段 | 編輯器裡是「第一個 Worker：整段複製…」開頭的程式 |
| 4 | 按右上角 **Deploy**（或 Save and deploy） | 畫面說已部署新版本 |
| 5 | 打開步驟 2 給你的網址（可以先按編輯器旁的預覽） | 一頁寫著「你現在連到的是 Cloudflare 在 ＿＿ 的機房」，有城市、機房代碼、國家和台北時間。**用手機（行動網路）再開一次同一個網址**，看到的城市可能不一樣 |

## 卡住時

| 狀況 | 怎麼辦 |
|---|---|
| 找不到 Workers & Pages | 剛開的帳號第一次要選一個子網域名稱（`<你的名字>.workers.dev`）；照畫面選好再回來 |
| 貼完部署，網頁還是 Hello World（或舊畫面） | 步驟 3 沒有全選刪掉就貼，或步驟 4 沒按 Deploy |
| 編輯器說語法錯誤 | 複製漏了一段；回 GitHub 重新「Copy raw file」 |
| 打開網址出現 1101 之類的錯誤 | 貼壞了；整段刪掉重貼 |

## 打開之後想一想（講師會帶）

| 傳統做法 | 你剛剛做的 |
|---|---|
| 租一台主機、裝作業系統、裝網頁伺服器 | 都沒有，貼一段程式 |
| 等幾小時到幾天才上線 | 幾秒 |
| 主機放在一個地方，遠的人比較慢 | 全世界各地機房就近回應，所以城市會不一樣 |
| 不管有沒有人來，主機都在跑、都在收錢 | 沒人用就不花錢 |

> 這一關不需要任何金鑰。後面 Claude 替你部署時，是用你設在環境裡的金鑰做**同一件事**——差別只是不用你手貼。
